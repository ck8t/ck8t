# Change: Block Debugger — Popup → Tab Panel (Daakia-style)
**Date:** June 19, 2026

## What changed

### Block Debugger redesigned as a center-pane tab

Replaced the floating `BlockDebuggerPopup` modal with a full-height `BlockDebuggerPanel` tab rendered in the center pane (same infrastructure as Settings, Wiki, Manager tabs).

- **`src/ck8t/debug/BlockDebuggerPanel.jsx`** (NEW) — full debugger UI in tab form:
  - Layout: block tile → HUD → file tabs → editor (left) + Run & Debug panel (right)
  - **No Run button** — HUD has: Continue, Step Over, Step In, Step Out, Restart, Stop, Mute Breakpoints
  - "Run block" button in the test-input section for standalone testing
  - Empty state when no debug session active
  - Auto-loads files when `nodeId` changes (right-click → Debug sets `nodeId`)
  - All breakpoint, watch, variables, call stack, console sections retained

- **`src/ck8t/stores/tabs-store.js`** — added `openDebugger()`, `closeDebuggerTab()`, `DEBUGGER_TAB_ID = 'debugger'`

- **`src/ck8t/debug/block-debugger-store.js`** — `openDebugger()` now also calls `useTabsStore.getState().openDebugger()` to switch the center pane; `setPaused()` auto-switches to the Debugger tab when a breakpoint is hit during execution

- **`src/ck8t/tabs/CenterPane.jsx`** — added `import BlockDebuggerPanel, { BugIcon }`, added `debugger` to `ICONS` map, added `{active?.kind === 'debugger' && <BlockDebuggerPanel />}` to tab body

- **`src/ck8t/sidenav/SideNav.jsx`** — bug icon button in rail (before Wiki); shows red dot indicator when breakpoints are active; clicking opens the Debugger tab; active highlight when Debugger tab is focused

- **`src/ck8t/AgentBuilderPage.jsx`** — removed `import { BlockDebuggerPopup }` and `<BlockDebuggerPopup />` render

### Fixed: "Cannot use import statement outside a module"

Block runner files use ES module `import` statements (`import { interpolateBag } from '../../block-utils.js'`). `BlockDebugEngine` ran code via `new AsyncFunction()` which doesn't support `import`.

- **`src/ck8t/debug/block-debug-engine.js`** — added `preprocessCode()` that strips `import { ... } from '...'`, `import X from '...'`, `export default`, and `export` keyword from code before passing to `AsyncFunction`. Imports `block-utils.js` and injects all exports as `__utils` parameter so stripped imports resolve correctly.

### CSS additions
- **`src/ck8t/debug/BlockDebuggerPopup.css`** — added `.bdp-panel`, `.bdp-panel-empty`, `.bdp-panel-empty-icon`, `.bdp-panel-empty-title`, `.bdp-panel-empty-sub` classes for the tab panel container and empty state
