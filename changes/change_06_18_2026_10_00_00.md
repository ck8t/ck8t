# Change Log — June 18, 2026

## Summary
fix: Workflow tab collision, node ID UUID remapping on import, autoPorts collapse, CUDA ID4 block fixes (D-shape, image preview, CORS)

## Changes
- fix: Auto-save effect in `AgentBuilderPage.jsx` was writing stale canvas state to the newly-activated workflow ID when switching tabs, making all tabs identical. Added `loadedWorkflowIdRef.current !== activeWorkflowId` guard — auto-save only fires once the canvas has fully loaded the target workflow.
- fix: Imported workflow JSON had hard-coded node IDs (e.g. `n_starter`, `n_loader`) that collided across tabs. All node IDs, edge source/target refs, and `subBlockValues` keys are now remapped to fresh UUIDs in `parseImportedWorkflowJSON()` via `_remapIds()`.
- fix: `autoPorts()` in `io-registry.js` was collapsing all typed input/output ports into a single `• input` entry. Now maps each named port individually.
- fix: `cuda_id4_loader` block had empty `inputs: {}` which triggered the fallback D-shape (`bs-handle`) connector. Fixed by adding a named `trigger` typed input port — renders as a small round dot in the port strip.
- fix: `cuda_id4_generate` block return value was returning raw base64. `extractMediaUri()` requires a `data:image/png;base64,` prefix — generate block now returns the full data URI.
- fix: `api_server.py` (RunPod FastAPI server) rejected requests from VS Code webview due to missing CORS headers. Added `CORSMiddleware(allow_origins=["*"])`.
- feat: Added `save_to_files` node to `cuda-id4/sample/animal-story-cuda.json` — fans out from `image_b64` alongside `show_preview`.
