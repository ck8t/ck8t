# Change — 06/18/2026 12:00:00

## Summary

Added a full Getting Started workflow library: 45 real, working demo workflows covering every core block, seeded into the Getting Started folder on fresh install. Added a "Restore Getting Started" button in Settings so users can re-add any demos they've deleted.

## Changes

### New: `src/ck8t/stores/getting-started-workflows.js`
- 45 exported workflow objects — one per block type — in the canonical `{ nodes, edges, subBlockValues }` format matching `demo-workflow.json`
- Real, working demos using free public APIs: `jsonplaceholder.typicode.com`, `api.github.com`, `dog.ceo`, `httpbin.org`, `api.open-meteo.com`, `numbersapi.com`
- Blocks requiring credentials (Slack, SMTP, Redis, PostgreSQL, MongoDB) have placeholder values and instructions to update before running
- All nodes use correct `sourceHandle` / `targetHandle` naming convention (`value` / `in_input`, `data` / `in_items`, etc.)
- Exports `GETTING_STARTED_WORKFLOWS[]`, `GETTING_STARTED_FOLDER_ID`, `GETTING_STARTED_IDS` (Set)

**Blocks covered by the 45 demos:**
`starter`, `user_input`, `text_template`, `function`, `agent`, `api`, `json_path`, `json_map`, `mapper`, `filter`, `sort`, `aggregate`, `for_each`, `for_loop`, `if_else`, `if_elseif_else`, `switch`, `ai_classifier`, `chain_of_thought`, `error_handler`, `delay`, `wait`, `variables`, `crypto`, `parallel`, `merge`, `webhook_request`, `http_response`, `schedule`, `image_url_preview`, `image_url_to_base64`, `slack`, `smtp`, `redis`, `postgresql`, `mongodb`, `table`, `master_agent`, `slave_agent`, `mcp`, `save_to_files`, `show_preview`
